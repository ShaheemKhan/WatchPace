# WatchPace

WatchPace is a React Native iOS companion app that helps runners build pace awareness through simple intervals and post-run insights.

## Overview
The iPhone app displays live workout guidance, while a lightweight watchOS companion shows current pace, interval stage, and next instruction.

## Problem
Runners often lose track of pacing during interval workouts and receive feedback only after the run.

## Solution
WatchPace provides real-time interval coaching, simple haptic cues, and a clear post-run breakdown.

## Features
- Custom interval workouts
- Live pace and distance display
- Haptic interval alerts
- Post-run pace splits
- Apple Health / HealthKit integration
- Apple Watch companion UI

## Tech Stack
- React Native + Expo
- TypeScript
- HealthKit via native modules
- watchOS companion app
- SQLite for workout history
